# Evidence and Validation Documentation

This directory is the documentation entrypoint for evidence that supports project claims: evaluations, benchmarks, validation methodology, and reproducible result interpretation.

It is distinct from adapters/evidence/, which contains runtime Evidence Adapter implementation.

## Current evidence surfaces

- [Skill Evaluation](../SKILL-EVALUATION.md) — how Skill effectiveness is evaluated.
- [Community Validation](../COMMUNITY-VALIDATION.md) — how external validation should be reproduced and reported.
- [Release Status](../RELEASE-STATUS.md) — maturity claims and current limits.
- [Validation report submission format](../../validation-reports/README.md) — current machine- and contributor-facing report corpus.

New documentation that interprets benchmarks or validation evidence should be routed through this index rather than added as an unindexed report at the repository root.

Fixture-only results must remain distinguishable from live-agent effectiveness evidence.
